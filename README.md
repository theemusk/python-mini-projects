# Python Mini Projects 🐍

A collection of beginner-friendly Python projects built to strengthen programming fundamentals and problem-solving skills.

## Projects

### 1. Student Grade Calculator
A command-line program that calculates total marks, percentage, and grade based on subject marks.

**Concepts used:**
- Variables and data types
- Lists and loops
- Conditional statements
- Functions
- Input validation and exception handling

## Tech Stack
- Python 3

## How to Run

1. Install Python 3.
2. Open a terminal in this directory.
3. Run:

```bash
python student_grade_calculator.py
```
